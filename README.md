# Чаван Чуду — редизайн сайта

Адаптивная демонстрация сайта ресторана: каталог блюд, поиск, категории, карточка блюда и корзина. Содержимое меню основано на публичном сайте [chavan-chudu.ru](https://chavan-chudu.ru/).

Это статический прототип для просмотра нового интерфейса. Он не отправляет заказы в ресторан, не принимает платежи и не сохраняет персональные данные посетителя. Цены и наличие требуют проверки перед подключением реального оформления.

## Локальный запуск

Нужен Node.js 22. Внешние npm-зависимости не требуются.

```sh
npm run dev
```

Откройте локальный адрес, который появится в терминале.

## Проверка и сборка

```sh
npm test
npm run check
npm run build
```

Готовые файлы сайта создаются в `dist/`.

## GitHub Pages

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow [pages.yml](.github/workflows/pages.yml) проверяет проект, собирает `dist/` и публикует его при отправке изменений в `main`. Его также можно запустить вручную через **Actions → Deploy GitHub Pages → Run workflow**.

Опубликованная демонстрация: [general-fox.github.io/Chavan/](https://general-fox.github.io/Chavan/).
