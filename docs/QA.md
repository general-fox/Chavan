# Проверка новой версии Чаван Чуду

Проверено 26 октября 2026 года.

- 143 позиции, 14 категорий, 143 фотографии. 58 блюд с добавками. Состав, цены и скидки перенесены из публичного меню; отсутствующие описания не выдумывались.
- 20 модульных тестов: сохранённая корзина, недопустимые позиции, округление, отдельные комплектации, лимиты добавок, адрес, российские номера телефона, неизвестная доставка.
- Браузер: 1440×1000, 768×1024, 390×844, 320×812. Горизонтальной прокрутки документа нет. Ошибок JavaScript и повреждённых изображений в проверенных сценариях нет.
- Проверены поиск по названию/описанию, сортировка цены, категории, избранное, добавление и изменение количества, сохранение после перезагрузки.
- Шурпа без хлеба = 790 ₽; с хлебной лепёшкой = 850 ₽. Они создают разные строки корзины. Аварский с бараниной 990 ₽ + бульон 150 ₽, две порции = 2280 ₽.
- Пройдено оформление с вымышленными контактами: ошибки рядом с полями, проверка состава, демонстрационное завершение. Данные контактов не записываются в storage и не передаются по сети.
- Мобильная корзина, доставка/самовывоз и относительные пути /Chavan/ проверены в браузере.
- Клавиатура: видимый фокус, Escape, удержание фокуса в модальных окнах и корзине, возврат фокуса после перерисовки. Учитывается prefers-reduced-motion.
- Вторичные тексты затемнены: базовый muted #5f6b59 даёт не менее 4.69:1 на основных светлых фонах. Это инженерная проверка, не сертификация полного соответствия WCAG.

## Границы демонстрации

GitHub Pages показывает интерфейс и локальные сценарии. Заказы не передаются в Monobox, оплат нет, доступность блюд не синхронизируется. Цена и время доставки требуют проверки адреса рестораном. Промокоды не активны. Публикация исключает сырые ответы исходного сайта и служебные токены; сборка использует разрешённый список файлов. Демоверсия содержит noindex, чтобы не конкурировать с основным сайтом в поиске.
