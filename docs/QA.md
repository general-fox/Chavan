# Проверка обновлённой версии Чаван Чуду

Проверено 26 октября 2026 года после переработки дизайна по замечаниям владельца.

## Дизайн и содержание

- Оригинальный `assets/original-logo.svg` используется целиком: файл совпадает с переданным владельцем SVG, без перекрашивания и замены знака.
- На компьютере категории расположены вертикально слева; текущая категория выделена, рядом виден счётчик блюд. На телефоне доступен отдельный диалог категорий.
- Четыре блюда дня размещены одновременно: Завтрак горца, Буррата с томатами, Ассорти чуду, Ассорти хинкал «Чабан». На компьютере — один ряд, на телефоне — два ряда по две карточки. Видны обычная цена, специальная цена и экономия в рублях.
- Акция Kinza Cola: 2 напитка при заказе от 5 000 ₽, доставка и самовывоз на всех точках. Условия и источник доступны из баннера. Подарок не добавляется в оплачиваемый каталог.
- 143 позиции, 14 категорий, 143 локальные фотографии. 58 блюд с добавками. Отсутствующие описания не выдумывались.

## Проверки

- 20 модульных тестов расчётов, нормализации корзины, отдельных комплектаций, лимитов добавок и проверки оформления проходят.
- Проверка локальных ресурсов: 7 JavaScript-файлов, 143 фотографии блюд, 2 акции, 156 ссылок; уникальные HTML ID и корректные связи акций с блюдами.
- Браузер: 1440×1000, 1280×900, 1024×900, 390×844, 320×740. Горизонтальной прокрутки документа нет. На ширине 1280 px корзина находится справа; на 1024 px открывается отдельной панелью.
- Проверены мобильный выбор категории, глобальный поиск «буррата», скрытие рекламных разделов при поиске и восстановление после очистки.
- Ассорти чуду, добавленное из блока блюд дня, синхронизируется с обычным каталогом; изменение количества из каталога обновляет обе карточки и сохраняет фокус в исходной карточке.
- Аварский с бараниной 990 ₽ + Говядина отварная 450 ₽ = 1 440 ₽. Добавка отображается в корзине и на проверке заказа.
- Пройдено оформление с вымышленными контактами: ошибки рядом с пустыми полями, проверка состава и демонстрационное завершение. Контакты удаляются из формы после завершения.
- Условия подарка открываются из баннера; в условиях акции блюд дня доступны все четыре блюда и переход в карточку.

## Границы демонстрации

GitHub Pages показывает интерфейс и локальные сценарии. Заказы не передаются в ресторан, оплат нет, доступность блюд не синхронизируется. Цена и время доставки требуют проверки адреса рестораном. Промокоды не активны. Персональные контакты не записываются в browser storage. Сборка использует разрешённый список файлов и исключает сырые ответы исходного сайта и служебные данные. Демоверсия содержит noindex.
